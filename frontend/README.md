# Frontend

Frontend-specific code lives in this folder, but the full project setup is documented in the root [README.md](../README.md).

## Quick Start

```bash
cp .env.example .env.local
npm install
npm run dev
```

Default local frontend URL:

```text
http://localhost:3000
```

Default backend URL expected by the frontend:

```env
NEXT_PUBLIC_API_URL=http://localhost:8080
```
